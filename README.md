# 🍔 Foodore - End-to-End QA Software Testing Portfolio

## 📌 Project Overview
**Foodore** is a fictional food delivery web application designed for Quality Assurance training, portfolio creation, and case study demonstration. 

This repository contains a complete Software Quality Assurance (SQA) project validating the core food-ordering user journey from user registration to order placement and history.
